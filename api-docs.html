Dokumentasi API

Referensi lengkap untuk menggunakan REST API Autospec.

Base URL

http://localhost:3000/api
POST

/auth/register

Mendaftarkan pengguna baru ke dalam sistem.

Request Body (JSON)

{
  "fullName": "John Doe",
  "email": "john@example.com",
  "password": "securepassword123"
}
POST

/auth/login

Otentikasi pengguna untuk mendapatkan JSON Web Token (JWT).

Request Body (JSON)

{
  "email": "john@example.com",
  "password": "securepassword123"
}

Response Sukses (200 OK) 

{
  "message": "Login berhasil",
  "token": "eyJhbGciOiJIUzI1NiIsInR...",
  "user": {
    "id": "uuid-string-here",
    "full_name": "John Doe",
    "email": "john@example.com"
  }
}
Protected Route
GET

/auth/me

Mengambil data profil pengguna yang sedang login berdasarkan token JWT.

Headers Diperlukan

Authorization: Bearer <Token_JWT_Anda>
